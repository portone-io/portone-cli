# portone auth

Authenticate with PortOne

```
portone auth <COMMAND>
```

## Commands

| Command | Description |
| --- | --- |
| [portone auth login](portone_auth_login.md) | Authenticate with PortOne Console |
| [portone auth status](portone_auth_status.md) | View authentication status |
| [portone auth token](portone_auth_token.md) | Print the current console access token |
| [portone auth logout](portone_auth_logout.md) | Remove local credentials without revoking the server-side token |
