# portone setup

Install PortOne plugins for AI coding assistants

```
portone setup [OPTIONS]
```

## Options

| Option | Description |
| --- | --- |
| `--allow-dirty` | Proceed even when the Git working tree is dirty |
| `--assistant <ASSISTANT>` | Assistant to configure (claude \| codex \| both) |
