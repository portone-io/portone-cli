# portone store set-default

Set the default store for a configuration profile

```
portone store set-default [OPTIONS] [ID]
```

## Arguments

| Argument | Description |
| --- | --- |
| `<ID>` | Store ID to save as the default |

## Options

| Option | Description |
| --- | --- |
| `--profile <NAME>` | Configuration profile to use |
| `--view` | Print the saved default store ID |
| `--unset` | Remove the saved default store |
